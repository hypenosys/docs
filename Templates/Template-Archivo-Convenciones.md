# 📁 Convenciones de Archivo y Cierre

*Porque tirar cosas a la basura es de cobardes; nosotros las guardamos aquí para que cojan polvo digital.*

## 1. Cuándo Archivar
- El proyecto/tarea ha finalizado con éxito.
- El concepto ha sido descartado (R.I.P.).
- La tecnología se ha vuelto obsoleta.

## 2. Pasos para el Cierre
1. **Limpieza:** Borrar archivos temporales o copias de seguridad locales.
2. **Documentación Final:** Asegurarse de que el estado final está reflejado.
3. **Post-Mortem:** (Opcional pero recomendado) ¿Qué aprendimos?
4. **Mover:** Trasladar la nota/carpeta a `08-Archivo`.

## 3. Nomenclatura en Archivo
- `[FECHA_CIERRE] - [Nombre Original]`.
- Ejemplo: `2023-12-01 - Sistema de Magia (Descartado)`.

## 4. Acceso a Documentos Archivados
*Nota: No se debe editar nada dentro de la carpeta 08-Archivo. Si quieres recuperar algo, cópialo fuera.*
