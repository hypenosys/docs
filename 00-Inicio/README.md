# Hypenosys Studio — Vault de conocimiento

Bienvenido al cerebro colectivo del estudio. Aquí vive el lore,
el diseño de juego, las decisiones técnicas y todo lo que no debería
perderse cuando alguien se va de vacaciones.

## Cómo funciona esto

Este vault está sincronizado con GitHub a través del plugin **obsidian-git**.
Cada miembro del equipo tiene una copia local que se sincroniza
automáticamente con el repositorio compartido.

Consulta [[00-Inicio/Onboarding-Obsidian-Git]] para configurar tu entorno.
